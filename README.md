# Muhammad Anees — Engineering Portfolio

A static, dark/light-theme engineering portfolio for Muhammad Anees, an AI Solutions Architect.
Ten case studies covering security operations, cyber-range training, multi-agent AI orchestration
and governance, AI-native DevSecOps, realtime communications, third-party integrations, application
security, multiplayer game engines, QA/release engineering, and platform architecture — all drawn
from a real engagement, with the client's name withheld under confidentiality throughout.

## Before you publish

Fill in these placeholders in `index.html`:

- `[YOUR EMAIL]` — appears in the top bar "Contact" link, the hero "Get in touch" link, and the footer.
- `[YOUR LINKEDIN]` — footer LinkedIn link.
- `[YOUR GITHUB]` — footer GitHub link.

No other edits are required to go live.

## Structure

```
index.html              the whole page
assets/css/style.css    all styling (dark + light themes)
assets/js/main.js       theme toggle, mobile nav drawer, scroll-reveal
```

No build step, no server-side code, no dependencies beyond Google Fonts. Works as a plain static
site — GitHub Pages, Netlify, S3, or any web server.

## Deploying to GitHub Pages

1. Create a new GitHub repository and push this folder to it.
2. In the repo's Settings → Pages, set the source to the `main` branch, root folder.
3. The site will be live at `https://<your-username>.github.io/<repo-name>/`.
